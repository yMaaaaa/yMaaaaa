## Bienvenue sur mon profil ! :) 👋

Je m'appelle Mattéo (aka yMaaaaa) — étudiant en **BTS SIO option SLAM** près de Pau, France 🇫🇷.

Mon objectif à moyen terme est de devenir développeur d'applications.
